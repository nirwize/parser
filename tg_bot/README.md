# Telegram-бот OLX

Бот использует существующий браузерный `olx_parser.Scanner`. Даты регистрации, категория, тип продавца (частные / все) и число подходящих объявлений настраиваются для каждого пользователя в Telegram. Общие категории и ограничения остаются в корневом `config.json`. В карточках нет номера телефона и данных продавца: отправляется только объявление, прошедшее проверку наличия телефона.

## Windows

Установите Python 3.12 или 3.13, затем из корня проекта:

```powershell
py -3.12 -m venv .venv_bot
.\.venv_bot\Scripts\python.exe -m pip install -r requirements.txt
.\.venv_bot\Scripts\python.exe -m playwright install chromium firefox
# Если tg_bot\.env ещё нет: Copy-Item tg_bot\.env.example tg_bot\.env
# Заполните BOT_TOKEN и ADMIN_ID в tg_bot\.env
.\.venv_bot\Scripts\python.exe -m tg_bot.main
```

На этом компьютере `browser_channel=auto` использует семейство системного браузера. Для Firefox Playwright нужен его собственный совместимый бинарник (`playwright install firefox`). Можно выбрать `chromium` в `config.json` и установить его. Для первого ручного входа необходим видимый рабочий стол на машине, где запущен бот.

## Ubuntu VPS

```bash
python3.12 -m venv .venv_bot
.venv_bot/bin/pip install -r requirements.txt
.venv_bot/bin/python -m playwright install --with-deps chromium
cp tg_bot/.env.example tg_bot/.env
# Заполните BOT_TOKEN и ADMIN_ID
.venv_bot/bin/python -m tg_bot.main
```

На VPS укажите `browser_channel: "chromium"` в `config.json`. Первый вход требует видимого браузера. На VPS без графического рабочего стола выполнить его нельзя; затем проверки могут использовать сохранённый профиль, пока OLX не завершит сеанс. Не отключайте CAPTCHA и не обходите ограничения сайта.

## Работа

Пользователь нажимает `/start`; владелец выдаёт доступ через «Админ-панель» по ID или @username уже зарегистрированного пользователя. Доступ привязан к ID и хранится в `tg_bot/bot.sqlite3`. Срок можно задать кнопками либо текстом `12 часов`, `45 дней`, `навсегда`. Продление прибавляет срок к действующей подписке. За сутки до истечения приходит напоминание. Блокировка и окончание срока останавливают автопроверку.

Главные кнопки всегда доступны в клавиатуре чата. Бот оставляет отдельное сообщение, к которому привязана клавиатура. При нажатии кнопки главного меню отправленное пользователем сообщение удаляется. При переходе между разделами бот удаляет предыдущее сообщение интерфейса и присылает новый экран; это работает и для экранов фильтров и админ-панели. После нажатия «Я вошёл в OLX — продолжить» приглашение к ручному входу удаляется. Сообщения с объявлениями, уведомления и «Ход проверки» остаются в чате. Telegram может отказать в удалении очень старого сообщения — тогда новый экран всё равно откроется.

В разделе «Сохранённые объявления» показаны подходящие объявления со ссылками на OLX, по восемь на странице. Бот сохраняет для каждого пользователя название, цену, категорию и ссылку после проверки. Ранее отправленные объявления, для которых эти поля не записывались, восстановить из старой базы нельзя. После обновления отправьте `/start`, чтобы клавиатура получила новую кнопку.

При запуске проверки бот создаёт одно сообщение «Ход проверки». После каждой просмотренной карточки он обновляет счётчики и показывает итог проверки последнего объявления; при завершении в том же сообщении появляется общий результат. Если Telegram временно ограничивает частоту редактирования, промежуточные состояния могут объединяться, но итоговые счётчики остаются актуальными. Подходящие объявления отправляются отдельными карточками.

При первой проверке бот открывает видимый браузер OLX на компьютере с ботом. Владелец входит в аккаунт и нажимает кнопку «Я вошёл в OLX — продолжить» в Telegram; проверка продолжается в том же окне, как в настольной программе. Отдельная кнопка «Вход OLX» в админ-панели позволяет подготовить профиль заранее, без просмотра объявлений. Данные браузера и резервное состояние сессии сохраняются в `tg_bot/browser_profile/`: после перезапуска бот повторно открывает этот профиль, а включённые автопроверки могут продолжиться. Если старый профиль содержит сохранённый сеанс без файла подтверждения, бот сначала пробует его без повторного запроса на вход. Наличие cookies само по себе не доказывает, что вход всё ещё действителен. Если OLX возвращает 403/429 или CAPTCHA, автоматические проверки приостанавливаются, но сохранённый профиль не удаляется; при необходимости владелец может повторить вход через админ-панель. Интервал по умолчанию 15 минут; владелец меняет его в админ-панели. Один профиль нельзя одновременно открывать в двух экземплярах браузера или бота.

В БД сохраняются пользователи, их фильтры, подписки, факты доставки по ID объявления и агрегаты проверок. Номера телефонов, имена продавцов и HTML в БД не пишутся. Cookies и другие данные сеанса находятся в профиле браузера. Папка профиля, `.env` и база исключены из Git; не передавайте их вместе с исходным кодом заказчику. На каждой установке владелец должен войти в свой аккаунт. Кнопка рассылки отправляет только текст, который владелец сам ввёл.

Поля города и даты публикации исходный парсер не подтверждает; бот их не выдумывает и не предлагает неработающие фильтры. Официальный API OLX для нужных произвольных объявлений бот не использует; API-ключи не требуются. Работа зависит от доступности публичной разметки OLX и разрешённого доступа к сайту.
